# Lab A4 - TextView, Button, EditText và xử lý sự kiện

**Họ tên:** Võ Văn Quốc Bảo

**MSSV:** 231A290036

**Học phần:** INT4211 - Lập trình trên các thiết bị di động

## Nội dung

- Máy tính cộng, trừ, nhân, chia và kiểm tra dữ liệu nhập.
- Tính BMI với chiều cao nhập bằng mét hoặc centimet.
- NC2: lưu 5 phép tính gần nhất, giữ lịch sử khi xoay màn hình.
- NC3: đổi màu kết quả theo phân loại BMI.

## Cách chạy

1. Mở thư mục `A4_231A290036` bằng Android Studio.
2. Chờ Gradle Sync, chọn module `app`.
3. Chọn máy ảo hoặc điện thoại Android API 24 trở lên và bấm **Run**.

Project sử dụng Java + XML, Java 17 và compileSdk 35.
